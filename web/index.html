ABOUT THE PROJECT

Published IEEE research turned into a working AI agent.

📄 IEEE Publication

Published at SCEECS 2026. Deep Learning Based Brain Tumor Classification Using Orange Data Analytics. 99% accuracy, AUC 0.999 in 10-fold cross-validation.

🧠 Methodology

InceptionV3 feature extraction (2048-dim vectors) → PCA dimensionality reduction → Neural Network classifier trained on 16,087 MRI images from 3 sources.

🤖 Agent Architecture

Gemini 2.0 Flash with function calling. ReAct loop: classify → explain → flag → report. Automatic fallback across 6 free Gemini models if one is busy.

🆓 100% Free

Gemini API (free tier at aistudio.google.com) + OpenRouter free vision models + Oracle Always Free VM. No credit card needed for the Gemini key.
